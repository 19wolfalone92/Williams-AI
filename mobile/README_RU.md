# Williams AI — независимое Android-приложение (без облачного API)

APK имеет собственный Android applicationId com.williamsai.offline и
не смешивается с торговым Williams. Сборка использует проверяемый фиксированный
SHA официального примера llama.cpp — см. UPSTREAM_LLAMA_CPP_SHA.

## Как получить APK
GitHub → Actions → Williams AI offline Android APK → успешный запуск →
Artifacts → WilliamsAI-offline-debug (APK и SHA-256 контрольная сумма).
Веса нейросети в APK не включены.

## Первый запуск
1. Скачайте совместимый GGUF Instruct-файл из надёжного источника, например
   Qwen3-1.7B GGUF Q4_K_M, соблюдая лицензию и проверяя SHA256.
2. На смартфоне выберите файл через стандартный Android file picker.
3. Приложение атомарно копирует модель в приватное хранилище;
   присваивает имя SHA-256 и не обрабатывает никаких биржевых ключей.
4. После загрузки задавайте вопросы по-русски без облачных AI API.
5. При перезапуске приложение попытается восстановить последнюю модель.

## Границы готовности
- Приложение запрашивает android.permission.INTERNET для добровольного поиска по Wikipedia и Google News. Включение только пользователем; по умолчанию поиск OFF.
- Android теперь содержит **только публичные read-only Binance Futures market-data GET**. Торговые операции и ключи в APK отсутствуют. Отдельный Python-модуль может открывать сделки только в Binance Futures DEMO после подтверждений.
- Публичные котировки доступны лишь после явной пользовательской загрузки; полноценная автоматическая проверка всех книжных правил ещё не готова.
  Добавлена приватная учебная память книжных фрагментов; она не является
  журналом исполненных сделок.
- CI-сборка означает лишь, что исходники компилируются. Нужна отдельная
  проверка реального запуска с настоящей моделью на телефоне.
- GitHub — хранилище и CI, не постоянно работающий сервер.

### Интернет-поиск и DEMO

В чате добавлена галочка «🌐 Искать в интернете». Если она включена и AI не располагает информацией, приложение запрашивает короткие результаты публичных Википедии и Google News (вопрос отправляется внешним сервисам) и приводит ссылки. Модель остаётся локальной. Факты из поиска требуют независимой проверки.

Для ручной DEMO-торговли реализован отдельный Python-клиент, **не включённый в APK**. См. [руководство](../docs/WILLIAMS_AI_RESEARCH_DEMO_RU.md). Никогда не используйте реальные Binance API-ключи или деньги.

### Изучение книг

После загрузки GGUF и личного SQLite-индекса выберите издание TC1/NTD/TC2/COURSE
и нажмите «Изучать выбранную книгу». AI последовательно обрабатывает доступный
текст без повторных нажатий; «Остановить изучение» прерывает сеанс.
Карточки сохраняются после каждого фрагмента; повторный запуск продолжает чтение. В фоне текущая порция отменяется,
завершённые карточки остаются. Выдуманные опорные цитаты отклоняются.
Релевантные учебные заметки подаются в чат с пометкой «не проверено».

В APK также включена учебная программа проекта по анализу, риску и проверке
гипотез. Это авторские заметки проекта, не цитаты из книг. Интернет-поиск
дополнен фиксированным каталогом официальных документов. Новая страница поиска
не вытесняет книжные источники из итогового запроса к модели.

Это накопление памяти, не переобучение весов GGUF и не фоновая служба.
Обучаемый paper-оценщик доступен отдельно в Python. Полный статус:
[AI_SELF_STUDY_RU.md](../docs/AI_SELF_STUDY_RU.md).


## Новое: биржевая история и волновые исследования ПРЯМО в Android (PR #30)

Эта часть APK не использует сервер Python. Новые Android/Kotlin-модули
`NativeWaveHistory.kt`, `NativeWaveStudy.kt`, `NativeWaveNotebook.kt`,
`NativeWaveSyncService.kt` встраиваются в ИМЕННО ОТДЕЛЬНОЕ приложение
`com.williamsai.offline` при сборке. Торговый `com.williamsbot` не изменён.

**Пользовательский запуск:** нажмите **«📈 Загрузить 15 ТФ»**.
Начнётся Android foreground `dataSync` с уведомлением и кнопкой остановки.
Загрузка не требует и даже не читает торговых ключей. Только зафиксированный
публичный `https://fapi.binance.com/fapi/v1/{time,exchangeInfo,klines}`.
Протокол проверяет время сервера, символ, `PRICE_FILTER`, календарные
закрытия 1m–1M, интервалы Binance 3d/1w/1M, OHLC, объёмы, целостность и
свежесть закрытых свечей. Введён строгий запрет на будущие свечи.

Изучаются **15 криптопар x 15 родных таймфреймов Binance Futures**. Каждая
свеча сохраняется в **приватной SQLite**. Последний сохранённый бар
перепроверяется при продолжении. На каждый ТФ за одно нажатие запрашивается
**не более двух страниц по 500 свечей**, с ограничением длительности
одного запуска примерно 24 минуты и запасом свободного места.
Это НЕ обещание сразу выкачать всю историю с момента листинга:
потребуются повторные ограниченные запуски и свободное место.
При ошибках HTTP451/429, разрыве связи или повреждении истории
дальнейшие данные не считаются годными для торговли.

**Изучение прошлых волн на телефоне:** отдельная таблица `wave_notes`
сохраняет последовательные проверенные исторические точки со смещением
120 баров. Для каждой точки анализируются ТОЛЬКО известные тогда свечи:
AO, AC, видимые со смещением линии Alligator, последние подтверждённые
пивоты и осторожный рыночный контекст. Заметки переживают рестарт.
Это причинное историческое исследование, **не переобучение весов GGUF
и не экспертная истина о степени волны**.

**Реальная Qwen в чате:** при вопросе о графике/волнах ИИ получает
компактный срез **своей локальной Android SQLite** — 15 ТФ только до
последней закрытой H1, AO/AC, Alligator, подтверждённый pivot, число
пройденных исторических checkpoint-ов. Если график не загружен, устарел
или данные повреждены, модель явно получает `UNKNOWN` вместо
выдуманных котировок. Ни одна из этих величин НЕ превращается в
подписанный ордер Binance.

**Границы автономности:** служба запускается **только по явному нажатию**
и продолжает работу при сворачивании приложения до завершения
ограниченного цикла. Android НЕ запускает её самостоятельно после
перезагрузки; Android 15+ ограничивает длительные dataSync-службы.
Повторное получение новых баров требует нового нажатия; полностью
автоматический надёжный периодический планировщик ещё не реализован.
Данное приложение **не** тестовый торговый движок и **не** размещает
сделки на Binance Demo. Реальный телефонный запуск должен быть принят
отдельно после проверки GitHub-сборки.
