# Williams AI — независимое Android-приложение (без облачного API)

APK имеет собственный Android applicationId com.williamsai.offline и
не смешивается с торговым Williams. Сборка использует проверяемый фиксированный
SHA официального примера llama.cpp — см. UPSTREAM_LLAMA_CPP_SHA.

## Как получить APK
GitHub → Actions → Williams AI offline Android APK → успешный запуск →
Artifacts → WilliamsAI-offline-debug (APK и SHA-256 контрольная сумма).
Веса нейросети в APK не включены.

## Первый запуск
1. Скачайте совместимый GGUF Instruct-файл из надёжного источника, например
   Qwen3-1.7B GGUF Q4_K_M, соблюдая лицензию и проверяя SHA256.
2. На смартфоне выберите файл через стандартный Android file picker.
3. Приложение атомарно копирует модель в приватное хранилище;
   присваивает имя SHA-256 и не обрабатывает никаких биржевых ключей.
4. После загрузки задавайте вопросы по-русски без облачных AI API.
5. При перезапуске приложение попытается восстановить последнюю модель.

## Границы готовности
- Приложение запрашивает android.permission.INTERNET для добровольного поиска по Wikipedia и Google News. Включение только пользователем; по умолчанию поиск OFF.
- Нет вызовов Binance, OpenAI и торговых операций **из Android APK**. Отдельный Python-модуль может открывать сделки только в Binance Futures DEMO после подтверждений.
- Пока нет подключения к котировкам, автоматической проверки книжных правил
  и локальной памяти торговых решений.
- CI-сборка означает лишь, что исходники компилируются. Нужна отдельная
  проверка реального запуска с настоящей моделью на телефоне.
- GitHub — хранилище и CI, не постоянно работающий сервер.

### Интернет-поиск и DEMO

В чате добавлена галочка «🌐 Искать в интернете». Если она включена и AI не располагает информацией, приложение запрашивает короткие результаты публичных Википедии и Google News (вопрос отправляется внешним сервисам) и приводит ссылки. Модель остаётся локальной. Факты из поиска требуют независимой проверки.

Для ручной DEMO-торговли реализован отдельный Python-клиент, **не включённый в APK**. См. [руководство](../docs/WILLIAMS_AI_RESEARCH_DEMO_RU.md). Никогда не используйте реальные Binance API-ключи или деньги.
