# Williams AI: приватный Qwen3-4B QLoRA по оригиналам книг (27.10.2026)

**Статус: подготовлена и проверяется новая реальная CUDA-процедура; GPU-сессия Qwen3-4B НЕ выполнена.** Это не обученный адаптер и не доказательство торгового мастерства. Отдельный проект Williams Bot 2.1 не трогать.

## Личный исходный материал
Сканированные и текстовые оригиналы принадлежат пользователю. Они **не** добавляются в GitHub или публичные CI-артефакты. В приватном индексе пока 539 из 642 страниц, в том числе лишь 20 из 122 страниц сканированного COURSE. Поэтому **полное изучение четырёх книг не завершено**, особенно рисунки волновых структур.

Готовый локальный архив пользователя `Williams_AI_4books_private_Qwen4B_source_corpus.zip` включает:
- `private_source/train.jsonl`, `validation.jsonl` и **недоступный обучающему циклу** `test.jsonl`;
- точные исходные SHA256 четырёх PDF, страницы, статус (OCR без экспертной проверки);
- `private_source/manifest.json`: SHA каждого split, двухстраничное page embargo, число покрытых и отсутствующих страниц.

Проверенный приватный архив (страницы с текстом не короче 30 символов): **387 страниц train, 57 validation, 77 test**; ещё 16 страниц исключены защитным эмбарго. Из 539 ранее индексированных непустых страниц 2 оказались слишком короткими для обучения (NTD PDF p.113 — 3 символа; COURSE PDF p.14 — 28 символов). Из 642 страниц исходных PDF 103 страницы вообще не содержат индексируемого текста. Это **text-only**, не метки вхождения WM1/2/3 и не экспертные подписи графиков.

## Тренировочный запуск на реальном NVIDIA GPU
Требуются пользовательский приватный диск/облако с распакованным архивом, **локальные** официальные safetensors и tokenizer Qwen3-4B, NVIDIA GPU со свободной памятью и CUDA сборки PyTorch + `bitsandbytes`. Программы не загружают базовые веса из интернета сами и не трогают биржевые счета. Все исходники и результаты хранятся вне репозитория. Обязательно зафиксировать точную ревизию официальной модели и проверить скачанные файлы.

```bash
python -m williams_ai.private_book_qlora \
 --private-source-dir /private/williams/private_source \
 --hf-base /private/models/Qwen3-4B \
 --new-output /private/outputs/williams-4b-session-001 \
 --steps 10 --rank 8 --max-tokens 512 \
 --authorize-private-gpu
```

Проверка целостности **без** GPU и без обучения:

```bash
python -m williams_ai.private_book_qlora \
 --private-source-dir /private/williams/private_source \
 --hf-base /private/models/Qwen3-4B \
 --new-output /private/outputs/unused \
 --audit-only
```

На GPU применяется NF4 4-bit с double-quant базой, PEFT LoRA rank8, frozen base, 10 шагов с сохранением weights и loss до/после отдельно по каждой книге. Адаптер сохраняется только при успешном gate валидации; при отказе экспортируется отчёт без адаптера.

## Допуск после обучения
1. Сначала провести **вне тренировки** test loss на отложенных страницах (это **текстовая** проверка, а не торговая).
2. Для графиков BTC/ETH и прочих инструментов собрать реальные причинные OHLC с D1/H4/H1/M15, без будущего при решении, и независимо разметить волны, WM1/WM2/WM3, зону, фрактал, вход/SL/выход двумя настоящими экспертами. Не выдавать машинные метки или скриншоты без шкал за независимую экспертизу.
3. Сравнить **исходную 4B и 4B+QLoRA** на одних новых chart holdout, отдельно оценить abstention, precision/recall сигналов, вероятности UP/DOWN/RANGE, итоговые paper сделки с издержками, восстановление защищённых ордеров на Demo/Android.
4. Без подтверждённого улучшения и стоп-защиты **запрещено** автоматическое продвижение адаптера и реальные ордера.

## Непреодолимые условия среды этой сессии
Текущая среда не содержит NVIDIA CUDA. Доступен GitHub Actions Linux CPU, но **нет подтверждённых подключённых Kaggle/GPU учётных данных, личных приватных datasets и GPU модели**. Создать GPU-обучение и подписать его результат через выдуманный хост/секрет невозможно. Код и приватные материалы подготовлены; фактический старт 4B произойдёт лишь в среде, которая действительно имеет CUDA и приватные исходники.

Этап с Qwen3-0.6B LoRA в предыдущем PR №46 реально завершён, его метрика 14,9% относится только к небольшой источниковой проверке и **не переносится** на Qwen3-4B.
