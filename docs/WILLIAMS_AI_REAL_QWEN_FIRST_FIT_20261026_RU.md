# Williams AI — старт настоящего обучения весов (исследовательская сессия)

## Что запускается
GitHub Actions `ai-real-pretrained-qwen-source-lora.yml` загружает **настоящую pretrained Qwen3-0.6B** из официального Hugging Face `Qwen/Qwen3-0.6B`, проверяет SHA-256 `model.safetensors`, выполняет **6 настоящих шагов оптимизатора LoRA** на CPU и сохраняет PEFT safetensors-адаптер с SHA-256 и отчётом. Это отличается от ранее существующего синтетического теста LoRA со случайно инициализированной Qwen.

Источник обучения — **уже опубликованные краткие проверенные по страницам карточки правил и учебные вопросы** из `knowledge/ADAPTIVE_TUTOR_PRACTICE_RU.json`. Ни одна исходная страница PDF, скриншот, клиентский материал, API-ключ или приватная SQLite-база не загружается на GitHub. Входы не заявлены как независимая экспертная разметка графиков.

Примеры группируются по `rule_id`; валидационные правила отделены от train, присутствуют TC1, NTD, TC2 и COURSE. Оценка по четырём источникам до и после записывается в `research_receipt.json`. Адаптер экспортируется **только как исследовательский артефакт**, независимо от результата validation gate; его наличие не даёт торгового допуска.

## Что НЕ доказывает запуск
- Не обучает реальной Qwen на приватных 642 страницах оригиналов и на книжных изображениях.
- Не является QLoRA для полной Qwen3-4B и не готовит её к автономной торговле.
- Не проверяет реальную волновую разметку, рыночные вероятности, систему WM1/2/3 на неизвестных графиках, PnL или Binance Demo.
- Адаптер HF PEFT **не** совместим напрямую с мобильной GGUF без отдельного подтверждённого преобразования.
- Успешный 6-шаговый CPU опыт — лишь **начало фактического обучения весов**. Если validation не улучшилась, адаптер остаётся не прошедшим даже начальную проверку.

## Запуск и контроль
Процесс запускается при открытии PR с изменениями в скрипте и workflow, либо через ручной запуск workflow. Проверить страницу Actions и скачать сохранённый `adapter_model.safetensors` вместе с `research_receipt.json`, если обучение фактически завершится успешно. Конкретный commit и модель (ревизия + SHA256) указываются в квитанции.

Следующий нужный этап — приватный GPU для Qwen3-4B, с **независимой** ручной разметкой книжных ситуаций и причинных графиков. Переучиваться на собственных ответах без экспертизы запрещено. Williams Bot 2.1 не меняется.
