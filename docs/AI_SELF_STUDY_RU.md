# Williams AI: самостоятельное изучение и проверяемое обучение

Изменения относятся только к 19wolfalone92/Williams-AI. Торговый Williams не изменяется.

## Что означает обучение

Есть два отдельных механизма. Локальная GGUF читает фрагменты личных книг,
создаёт учебные карточки и использует их в дальнейших ответах. Это постоянная
внешняя память, а не изменение нейронных весов. Отдельная небольшая логистическая
модель действительно обучает числовые коэффициенты по paper-оценкам истории.
Ни один из этих механизмов не имеет доступа к автоматической торговле.

Нельзя передать знания большой модели целиком одним заданием. В проект
добавлена доступная учебная программа: источники и издания, no-lookahead,
структура, AO/AC, Alligator, мудрецы, волновые альтернативы, риск, исполнение,
проверка гипотез и типичные ошибки исследования. Это учебные заметки, не новые
книжные аксиомы. Реестр проверенных страниц остаётся отдельным.

## Книги и OCR на компьютере

Нужны личные оригиналы четырёх книг, соответствующие контрольным суммам
`knowledge/SOURCE_RULE_CARDS.json`. Публичный репозиторий не включает книги,
распознанный текст или частную SQLite. Установите pypdf; для сканов — Poppler
и Tesseract с языком источника. Сканы Course на английском используют `eng`.

Примеры путей предполагают личный каталог `/private` вне git checkout:

```bash
python -m williams_ai.book_cli --db /private/books.db ingest TC2 /private/tc2.pdf
python -m williams_ai.book_cli --db /private/books.db ocr COURSE /private/course.pdf --output /private/course-ocr --limit 8
python -m williams_ai.book_cli --db /private/books.db ingest COURSE /private/course.pdf --ocr-dir /private/course-ocr
```

OCR можно продолжить с `--start-page 9`. Повторный запуск использует завершённые
страницы и проверяет паспорт источника/конфигурации. Отсутствие текста и ошибки
отмечаются явно. Распознавание текста не подтверждает чтение графиков.

## Изучение и долговременная память

```bash
python -m williams_ai.research_cli study --books /private/books.db --memory /private/study.db --model /private/model.gguf --edition TC2 --budget 4
python -m williams_ai.research_cli report --books /private/books.db --memory /private/study.db
python -m williams_ai.research_cli ask 'фрактал и ангуляция' --books /private/books.db --memory /private/study.db --edition TC2
```

Повторный study продолжает с ещё не обработанного фрагмента. Прогресс
фиксируется после каждой успешной карточки и разделяется по SHA-256 модели.
В карточке проверяются формат и реальное присутствие опорной цитаты в
исходном фрагменте. Это проверка происхождения, не семантической правильности.
Все выводы остаются SOURCE_DERIVED_UNVERIFIED; вопросы, противоречия и графики
нуждаются в независимой проверке. После трёх ошибок фрагмент остаётся для
ручного разбора, чтобы не блокировать последующие страницы навсегда.

В `chart_cli` доступен `--study-memory /private/study.db`. Первоисточники имеют
приоритет в ограниченном контексте; учебная память не вытесняет страницы книг.

## На телефоне

1. Установить отдельный Williams AI и загрузить совместимую GGUF.
2. Кнопкой книги импортировать приватный SQLite-индекс четырёх изданий.
3. Выбрать TC1, NTD, TC2 или COURSE, нажать «Изучить следующие 3 фрагмента».
4. Повторить для продолжения. Завершённые карточки сохраняются после каждого
   фрагмента; уход в фон прерывает текущую порцию. Веса GGUF не изменяются.
5. Задавать вопросы: релевантные конспекты подаются в чат с явной пометкой,
   что они не проверены. Источники книг и конспекты не объединяются в аксиому.

Это работа по запросу в открытом приложении, не фоновая служба круглосуточного
обучения. На Android пока нет модуля обучения paper-оценщика и живого торгового
контура. Python-память и Android-память независимы; синхронизация не реализована.

## Интернет

```bash
python -m williams_ai.research_cli ask 'Binance Futures documentation' --memory /private/study.db --web
```

Без `--web` исходящих запросов нет. В сети передаётся публичный вопрос;
книги, конспекты и счета не загружаются. Проверяется весь вопрос до усечения:
явные ключи, секреты, email и длинные идентификаторы блокируются.
Это эвристическая защита; формулируйте вопрос без персональных сведений.

Python сначала обращается к подходящим адресам из фиксированного каталога
официальных документов Binance, llama-cpp-python, pypdf и первичного исследования
переобучения, затем к Wikipedia. Сохраняются URL, время получения и фрагмент;
кэш используется не дольше 24 часов по умолчанию. Сетевые сбои возвращаются явно.
Это ограниченный исследовательский поиск, не универсальный браузер.
Android добавляет официальные документы к имеющимся Wikipedia/Google News.

Текст сайтов является недоверенными данными. Ни статья, ни конспект не могут
изменить код, риск-лимиты, стопы или отправить ордер.

## Обучаемый paper-оценщик

```bash
python -m williams_ai.research_cli learn-paper /private/chart.json --timeframe H1
```

Нужен формат chart_cli и достаточно непрерывных закрытых свечей. Признаки
вычисляются только по прошлому и текущему закрытому бару, вход оценивается по
следующему open. LONG/SHORT — исследовательские примеры через фиксированный
интервал, не объявленные сигналами TC2. Стоп фиксируется через ATR; при гэпе
используется худшая цена open. Комиссия и проскальзывание включены. Промежутки
train/validation/test разделены хронологически, пересекающиеся метки на границах
удаляются. Гиперпараметры и порог зафиксированы до test.

Горизонтальная оценка цены через 12 баров служит меткой для исследования,
не является правилом закрытия кампании. Funding, ликвидность, частичные
исполнения и портфель не моделируются. Повторный подбор по test запрещает
считать этот участок независимым; потребуется новый архив.

Первый фиксированный эксперимент: 999 H1 ETHUSDT, 11 сентября — 22 октября
2026 UTC. На test Brier score 0.23426 против 0.22693 постоянного прогноза из
train (меньше лучше). Преимущество модели не подтверждено; при фиксированном
пороге 0.6 примеры не отобраны. Результат и коэффициенты сохранены в
`examples/ai_learning_experiment_eth_h1.json` как неудачный исследовательский
эксперимент. Параметры после просмотра test не подбирались.

## Что проверено и что пока неизвестно

Тесты проверяют сохранение прогресса, границы изданий, ложные опорные цитаты,
no-lookahead признаков, удаление пересечений меток, независимость обучения от
изменений test, стоимость исполнения, запрет сети без включения и изоляцию
торговых функций. Android проверяется сборкой CI и статическими контрактами.

Не подтверждены: качество реальных GGUF-конспектов на конкретной модели,
понимание всех графиков, полноценные сложные волны, прибыльность и запуск
новой версии на телефоне. Ни присутствие книг в индексе, ни зелёные тесты
не дают процента понимания книг.
