# Williams AI — локальный языковой ИИ без облачных API

## Где находится ИИ

Репозиторий **хранит** программу, анализаторы, тесты, заметки и журнал изменений. Сам GitHub не является непрерывно работающим вычислительным сервером для языковой модели. GitHub Actions запускает проверки при коммитах; расчёты реального ИИ выполняются **на вашем устройстве** после установки программы и весов модели.

## Быстрый старт на компьютере

1. Скопировать репозиторий: `git clone https://github.com/19wolfalone92/Williams-AI.git`.
2. Создать Python venv и установить локальный runtime: `python -m pip install llama-cpp-python`.
3. Отдельно получить совместимую GGUF Instruct-модель (например, компактную модель ~0.5–1.5B параметров) от правообладателя или надёжного поставщика, проверить лицензию и контрольную сумму. **Веса не входят в этот репозиторий**.
4. Сохранить модель как `models/williams-local.gguf`. Весь каталог весов и GGUF-файлы исключены из Git.
5. В корне проекта:

```bash
python -m williams_ai.cli examples/ai_market_snapshot.json
python -m williams_ai.cli examples/ai_market_snapshot.json \
  --local-model models/williams-local.gguf \
  --knowledge-dir knowledge \
  --question "Что известно о волновой структуре H1 и AO?"
```

После получения весов все вопросы обрабатываются **без интернета, без токенов и без OpenAI API**. Нужны ресурсы CPU/RAM, а для поддержки GPU — совместимый llama.cpp и драйверы.

## Ограничения и безопасность

- Без файла GGUF программа формирует только детерминированный аналитический отчёт. Это **ещё не нейросеть**.
- CI проверяет Python-контракты через имитацию модели, но не запуск настоящих весов и не качество прогнозов.
- Сейчас вход — локальный JSON-снимок, а не самостоятельное чтение графиков или Binance.
- Исходный Williams Bot из другого репозитория не меняется. Торговые модули, скопированные из оригинала, не вызываются из williams_ai.
- Ответ нейросети — объяснение, не разрешение торговать. Не гарантирует соответствия книгам или прибыльности.
- Файлы книг, личные данные и ключи биржи не добавлять в публичный GitHub.
- Android-приложение, в котором модель реально работает на телефоне, пока не собрано. Его придётся разрабатывать и проверять отдельно (например, JNI с llama.cpp).
- Мы не обучали базовую языковую модель с нуля; она используется локально вместе с нашими алгоритмами и заметками.
