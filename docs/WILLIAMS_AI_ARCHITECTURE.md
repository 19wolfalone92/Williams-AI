# Williams AI — архитектура независимого локального аналитика

## Источник
- Изолированный репозиторий 19wolfalone92/Williams-AI.
- Снимок 19wolfalone92/Williams — зафиксирован в SOURCE_SNAPSHOT.md.
- Основная торговая система не меняется.
- ИИ не вызывает Binance Execution Door, не читает ключи и не исполняет ордера.

## Только локальные вычисления
- Python: пакет williams_ai, анализ offline JSON-снимков и проверка no-lookahead.
- GGUF-модель локально через llama-cpp-python; файл пользователя хранится только на его устройстве.
- Поиск заметок через локальный Markdown/text, без облачной векторной БД.
- Вызовы облачных AI API удалены из пакета: нет OpenAI, токенов и вызовов инференса на сервере.
- Отдельное Android-приложение собирается из фиксированного upstream llama.cpp Android-примера.
- APK имеет applicationId com.williamsai.offline, не запрашивает INTERNET permission и не включает веса модели.
- GitHub хранит исходники, тесты и собирает APK; выполнение AI происходит на смартфоне/ПК.

## Доказательства и ограничения
- Автоматические тесты проверяют форматы данных, no-lookahead, изоляцию секретов, локальный runtime через fake engine и статические Android-контракты.
- Реальная модель GGUF и качество её объяснений ещё требуют проверки на настоящем устройстве.
- Чат пока не получает историю свечей автоматически: это не автономный рыночный прогнозист.
- Волны, AO/AC и сигналы передаются в структурированном виде; их правильность не подтверждается только по полям отчёта.
- Чтение книг допускается из личных локальных копий при соблюдении прав; нельзя выкладывать полные защищённые тексты в публичный GitHub.
- Никакого обучения на live сделках без очистки данных, проверок и человеческого утверждения.
