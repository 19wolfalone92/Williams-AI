# Williams AI — первый фактический экзамен знаний Qwen3-4B
**Дата протокола:** 2026-11-11

## Что выполняется сейчас
- GitHub Actions запускает **настоящую публичную базовую Qwen3-4B**, а НЕ созданный нами обученный LoRA-кандидат.
- Файл публичного GGUF `unsloth/Qwen3-4B-GGUF/Qwen3-4B-Q4_K_M.gguf`; до инференса сверяется жёстко закреплённый SHA256 `f6f851777709861056efcdad3af01da38b31223a3ba26e61a4f8bf3a2195813a`.
- Зафиксирован набор 16 заданий (**по 4 на TC1, NTD, TC2, Profitunity Course**) из уже существующего 32-задачного исходного экзамена.
- На одной модели последовательно исполняются две сопоставимые группы: `closed_book` — только вопрос, `source_assisted` — **тот же вопрос** плюс автоматически выбранные открытые рецензированные карточки (не оригинальные страницы книги).
- **Ответы и ключи правильных ответов не передаются модели.** Невнятные ответы считаются ошибками, а не «воздержался, значит прав». Отдельно считаются потерянные и приобретённые правильные ответы, результаты по изданиям и средняя baseline по часто встречающемуся варианту.
- В отчёте закрепляются хэши модели и протокола, результаты, поле `user_trained_model_benchmarked=false`, `execution_allowed=false`. Итоги не являются оценкой истинного владения материалами четырёх книг: вопросы написаны разработчиком, опубликованы в коде, а 16 кейсов не являются независимой экспертной разметкой рыночных графиков.

## Отдельно: исторический GPU-кандидат
- Существующий запуск 50 QLoRA микрофаз завершился настоящими обновлениями градиента, но независимая предметная проверка показала `110/360` у родителя и `115/360` у кандидата; `research_gate_passed=false`.
- Архив выбранного `checkpoint-500` в GitHub Actions **зашифрован** и не представлен в этом исследовательском CI как подтверждённый `adapter.gguf` + `runtime_manifest.json`. Публичную базовую Qwen3-4B **запрещено** выдавать за этот обученный адаптер.
- Для честного следующего A/B/C теста (база / обученный адаптер / обученный адаптер + поиск) требуется локально экспортировать **подлинный** адаптер и проверенный manifest. `python -m williams_ai.knowledge_abc_exam_v1 --model <verified-base.gguf> --expected-sha256 <sha> --lora-adapter <private-adapter.gguf> --lora-manifest <private-runtime_manifest.json> --output <new-private-report.json>`. Никакие приватные книжные страницы или ключи не коммитить.

## Что означает успех
1. Модель верно отвечает не только на простые примеры, но и на те, которые ранее путала (волновые степени, NTD AC, NTD Alligator, TC2 Stop/Reverse, Course Hump/Thumb).
2. Режим с источниками не превращает неверное обобщение в «правильное» без доказанной связи со страницей, не смешивает правила разных книг.
3. Сравнение **на одной и той же проверенной модели** не имеет регрессий в безопасных решениях.
4. Следующий экзамен должен содержать действительно новые графики, экспертные волновые метки и последовательную историю с закрытыми свечами без будущих данных. Актуальные 16 MCQ **не** заменяют такую оценку.

Никакие результаты этого эксперимента не дают разрешения на сделки или автоматический перевод нового QLoRA в торговлю.
