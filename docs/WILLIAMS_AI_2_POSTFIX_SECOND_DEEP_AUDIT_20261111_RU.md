# WILLIAMS AI 2.0 — повторный аудит после исправления блокеров
**11 ноября 2026 | исследовательская ветка `research/learning-audit-remediation-20261111` | PR #75 | без допуска к реальной торговле**

## 1. Результат первого прохода: что исправлено в коде

| Проблема | Изменённый механизм | Проверка / ограничение |
|---|---|---|
| A1: dataset SHA только по case_id | `check_corpus` хеширует всё каноническое содержание, включая изменения ответа, книги, cutoff, графика, рецензий | CPU regression: изменённый утверждённый вопрос теперь меняет SHA |
| A2: WAIT без рассуждений набирал 100% | `grade_blind` требует строгий ответ, отмечает decision macro-recall, wave/squat знаменатели, abstention и confidence Brier | CPU regression: пустой WAIT отклонён; **семантическая правильность объяснений не доказана** |
| A3: новый SFT не соединён с QLoRA | Добавлен `reasoning_qlora_bridge_v2.py`, actual CUDA opt-in + bounded answer-only Qwen tokens, train/validation-only handoff | CPU schema/tokenizer tests; **реального Qwen GPU обновления ещё нет** |
| A4: правило, ошибочное на validation, отсутствует в train | `adaptive_schedule` подбирает примеры по общим навыкам, а не невозможному совпадению rule-ID; отдельный источник review-метаданных `reasoning_feedback_v2.py` | CPU regression NTD.AC → momentum train from a different rule |
| A5: BTCUSDT/BTCUSDC проходят как разные рынки | Сплиты группируются по underlying через `chart_supervision._underlying_asset` | CPU test: quote alias cross-split отклонён |
| A6: восемь H1 свечей вместо контекста | Подтверждённые H1/H4/D1 префиксы, 220+ свечей для расчётов, закрытые индикаторы, 4 range, подтверждённые pivots; контекст сжат без потери токенов ответа | CPU test full snapshots; H4/D1 «будущие» и устаревшие кадры блокируются |
| A7: parent и candidate пишут в одну память | SQLite с `(run_id,model_id,case_id)`, отдельные источники книжных правил, фильтры edition, reviewed error recall | CPU regression: независимые гипотезы двух моделей в одной DB |

Тесты software-контрактов **не доказывают**, что Qwen стала самостоятельно мыслить или прибыльно торговать.

Дополнительно реализовано:
- Версионированная память с исходной книгой/правилом/хешем и ссылками на позднейшую проверку.
- Отдельная очередь проверенных ошибок validation; raw validation/test answers в sampler не передаются.
- Время **фактической записи** экспертной рецензии и ошибки фиксируется и проверяется вместе с объявленным `reviewed_at`: backdated reviewer feedback не может задним числом попасть в исторический as-of.
- Сжатие входного рыночного контекста с *no truncation* для исходного ответа и книги.
- Действующая GPU entrypoint требует явно разрешённые приватные данные и одобренный корпус; не допускает test gold.

## 2. Новые результаты независимой проверки четырёх ПОДЛИННЫХ PDF

Это проверка оригиналов пользователя локально, **не пересказ README**. Контрольные суммы SHA-256 и число страниц совпали с `knowledge/SOURCE_RULE_CARDS.json`.

| Книга | Всего страниц | С извлекаемым текстом pypdf | Страницы без извлекаемого текста |
|---|---:|---:|---:|
| Trading Chaos 1 | 140 | 140 | 0 |
| New Trading Dimensions | 156 | 155 | 1 (стр. 1) |
| Trading Chaos 2 | 224 | 224 | 0 |
| **Profitunity Course** | **122** | **0** | **122 — целиком изображение/скан** |

**Критическая находка:** из самого оригинального Course PDF нельзя извлечь ни одной текстовой страницы стандартным парсером. Ранее декларированные `121/122` страниц текста могли относиться к *отдельному OCR-слою/перенесённым OCR-файлам*, а не к исходному PDF. OCR не означает понимание диаграмм/рисунков и не является независимо проверенным книжным ключом.

С этим связан исправленный source-bug: раньше `grounded_inference.verified_private_book_pages` мог маркировать OCR-источник как обычный индексированный текст. Теперь при `source_type=PDF_TEXT_WITH_UNREVIEWED_OCR` статус явно `PRIVATE_OCR_UNVERIFIED_NEEDS_PAGE_IMAGE_REVIEW`. Local Qwen runtime запрещает принимать его как подтверждённую книгу без последующей проверки.

Добавлен `scripts/ai_audit_original_books_v2.py`: проверяет **файлы и страницу** по SHA-256, классифицирует точные цитаты против парафразов/непроверенного OCR, не сохраняет содержимое PDF в репозиторий.

## 3. Новые и сохраняющиеся препятствия, обнаруженные вторым аудитом

### P0-1. Невозможно построить корректный курс по непрочитанным графикам и OCR

У Course PDF — 122/122 страниц без machine-text. Там встречаются рисунки, волновые схемы и специфические бары. Нужна проверка текста OCR **на уровне изображений и страничных графиков**, затем проверенная страница→рисунок→правило→положительный/отрицательный учебный пример. Предоставлять модели OCR с меткой `REVIEWED_PAGES` без реальной независимой проверки — источниковая ошибка. Ни один код сам не может гарантировать человеческую точность этих страниц.

### P0-2. Семантическое доказательство подлинности `book_evidence` всё ещё слабое

`verify_case` защищает page/edition/sha и два заявленных reviewer-ID, но поле `checked_by_reviewers=true` остаётся декларацией. Синтетический тестовый пример с **заведомо не взятой из книги строкой** может пройти структурную проверку. Программа теперь умеет локально отчитываться, найдена ли строка *дословно* на странице оригинала, но этот путь **не заменяет сверку смысла парафраза двумя компетентными рецензентами**.

До реального GPU нужно потребовать прикреплённую доказательную страницу, пометку verbatim/approved paraphrase и реальные независимые рецензии; не придумывать подтверждения AI-генератором.

### P0-3. Нет независимого корпуса экспертных РЫНОЧНЫХ примеров

Аудит старого `frozen()` (train 864 / validation 224 / test 360) доказал **0 positive `wave_confirmed` и `squat_verified` во всех split**. Без реальных примеров подтверждённых волн, Squat, отмен и контргипотез нельзя научить качественному различению. `readiness` уже блокирует новый GPU, но необходимые независимые ответы не созданы.

### P0-4. Фактическая эффективность Qwen3-4B не проверена после изменений

Оригинальный эксперимент 50×20 шагов дал 110/360→115/360, +1,39 п.п., ошибки AC 54/72→50/72, превышения риска 15→16, четыре research-gate false. Новый тренировочный мост протестирован на **CPU/синтетических** данных, не на реальном адаптере. Нового измеримого качества в этой ветке пока **нет**.

### P0-5. «Слепота» исторического экзамена ещё не является внешне аттестованной

`run_blind_replay` принимает полные test case объекты, хотя в model_predict передаёт только `question_only`; вызывающая программа всё ещё может получить gold через замыкание/другой импорт. Это не строгая изоляция. Рекомендованный путь — экспорт `test_prompts.jsonl`, **отдельный** процесс инференса без `test_gold`, immutable prediction receipts и независимое offline `compare` после заморозки модели.

### P1-6. Список книжных правил пока существенно меньше четырёх книг

В `SOURCE_RULE_CARDS.json` — **37 проверенных коротких карточек**: TC1 14, NTD 8, TC2 8, COURSE 7. Всего страниц 642. Соотношение числа карточек и страниц не является прямой мерой полноты, но полного покрытия всех книжных примеров/рисунков **не доказано**.

### P1-7. «Память ошибок» стала причинной, но не автономно исправляет веса

`reasoning_feedback_v2.ReviewedFailureJournal` сохраняет исправляемые **категории** ошибок validation после рецензии, передаёт только metadata адаптивному курсу. Без одобренных новых примеров тренер не обновляется. Это правильный запрет на самоусиление неподтверждённых ошибочных предположений, однако это **не полностью автономное самообучение**.

### P1-8. Источники прежних ошибок остаются изолированы по эксперименту

`HypothesisMemory` и `ReviewedFailureJournal` намеренно привязаны к `run_id/model_id`. Это предотвращает утечку и смешение parent/candidate, но долгосрочную передачу проверенных уроков следующей модели необходимо делать **явной**, с сохранением происхождения, срока доступности и запретом test gold. Фоновая перенастройка всех весов не должна запускаться автоматически.

### P1-9. Проверка смысла объяснений не заменяется структурной метрикой

Новый `grade_blind` требует evidence/counterevidence/invalidation и измеряет accuracy, часть calibration и баланса. Всё ещё невозможно автоматически установить, истинны ли объяснения по авторским рисункам Вильямса. Необходимы два независимых рецензента на собственно *обоснованиях*, а не только структурные хеши.

### P1-10. Временные ряды имеют большой overlap внутри split

Сохранены целостность временны́х префиксов и кросс-сплит isolation underlying. Однако соседние rolling-prefix окна одного актива внутри одной выборки не являются независимыми наблюдениями. Требуются отчёты об effective sample size, режимах рынка, корреляции и embargo; обучающую точность нельзя выдавать за robust generalization.

### P1-11. Входы модели всё ещё не воспроизводят весь визуальный язык книги

`question_only` теперь содержит H1/H4/D1, строго подтверждённые фракталы, OHLCV и технический numeric summary. Но это **не полноценное машинное зрение по исходным графикам**. Волновой degree и Squat требуют надёжной интерпретации структуры/объёмов, а численный OHLCV не доказывает намерения автора. Отдельный визуальный экзамен по изображению и сравнение с expert annotations обязательны.

### P1-12. Рыночный риск/исполнение не может быть полностью квалифицирован исследовательским экзаменом

`grade_blind` не оценивает истинное исполнение стоп-ордеров, funding, margin/liquidation, реально подтверждённые SL, пропуски WebSocket. Экспериментальную модель **нельзя подключать к live trading**. Отдельные TC2 order/risk gates должны оставаться независимыми.

## 4. Следующий безопасный цикл, который теперь технически подготовлен

1. Проверить вручную OCR **всех 122 страниц Course**, начать с семантически важных рисунков, сомнительных OCR и отсутствующей страницы NTD; сохранять отдельные источники и page/image hashes.
2. Собрать приватные double-reviewed кейсы: положительные/отрицательные волны и Squat, альтернативы, отмены, AC/AO и реальные закрытые рынки H1/H4/D1. Отдельно сохранить `UNKNOWN` вместо ложного gold.
3. CPU preflight → `prepare_gpu_handoff` → answer-only QLoRA on CUDA with `reviewed_train_validation.jsonl` (без test gold) → per-checkpoint dev gate.
4. Проверять несколько независимых seeds, parent vs candidate, долю corrected/regressed, confidence Brier, риски и сохранение всех 4 источников.
5. Полностью отдельный blind process с prompt-only кейсами и sealed predictions; независимая оценка на неизвестных активам/периодам; **никакого model promotion до нулевой критической ошибки риска**.

**Состояние:** 7 исходных программных блокеров имеют тестируемые исправления; исправлены ещё OCR provenance и backdated review causality. Достоверных новых экспертных рыночных меток, реального Qwen-v2 обучения и доказанного улучшения нет. Williams Bot и live trade не менялись.
