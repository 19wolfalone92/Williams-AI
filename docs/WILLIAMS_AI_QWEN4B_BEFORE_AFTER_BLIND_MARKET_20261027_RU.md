# Williams AI — настоящая слепая проверка Qwen3-4B после GPU QLoRA (27.10.2026)

**Обязательное разграничение:** подготовленная Qwen3-4B — это **план обучения с проверенными контрактами**, но обученной Qwen3-4B по оригиналам и графикам в текущей среде пока **нет**. Фактическая QLoRA на CUDA требует приватного NVIDIA GPU, не предоставленного инструментам этого чата. Без реальной контрольной точки скрипт откажется создавать сравнение. В PR №46 ранее удалось провести настоящее 6-шаговое LoRA обучение **Qwen3-0.6B**, не Qwen3-4B.

## Почему новая проверка не подделывает качество
1. При обучении оригиналов четыре PDF представлены как **текст**, с отложенными страницами и нерецензированным OCR. Это не валидированные «волны» и не экспертное распознавание книжных рисунков.
2. `ai_seal_15pair_blind_charts.py` уже отдельно запечатал **30 независимых as-of вопросов** на 15 монетах Binance Futures H1 и отдельные реальные будущие цены. Нельзя использовать второй архив до того, как ответы обеих версий Qwen сохранены.
3. `qwen4b_blind_evaluation.py predict` физически читает **только** архив вопросов, официальную локальную Qwen3-4B и действительно обученный локальный адаптер с проверенным SHA. Она вычисляет пару ответов исходной и адаптированной Qwen, по **одним и тем же доступным по времени индикаторам**. Ответы — нормализованные оценки трёх следующих текстовых токенов UP/DOWN/RANGE; это не доказанная калибровка или оценка волны.
4. Лишь после сохранения ответов `qwen4b_blind_evaluation.py grade` читает отдельные ключи исхода через 24 H1 и считает accuracy и multiclass Brier для каждой версии. Она не может честно оценивать WM1/WM2/WM3 или качества волновых входов без независимых человеческих меток.
5. Даже если Brier оказался лучше на 30 примерах, **это не основание для реальных денег** — требуется большой по-настоящему независимый walk-forward, комиссия, проскальзывание, проверка защитных стопов и Android.

## Запуск в собственном изолированном CUDA окружении

После **успешного** CUDA обучения модулем `williams_ai.private_book_qlora`:

```bash
# Прямые скачанные артефакты: архив вопросов БЕЗ ключей,
# отдельно и недоступно на этапе predict — архив будущих ответов.
python -m williams_ai.qwen4b_blind_evaluation predict \
  --questions /private/holdout/model_questions.jsonl \
  --hf-base /private/models/Qwen3-4B \
  --source-adapter /private/outputs/Williams-Qwen3-4B-source-LoRA-session001 \
  --new-output /private/outputs/qwen4b_blind_precommit.json

# Только ПОСЛЕ завершения предыдущей команды:
python -m williams_ai.qwen4b_blind_evaluation grade \
  --predictions /private/outputs/qwen4b_blind_precommit.json \
  --withheld-outcomes /private/holdout/WITHHELD_OUTCOME_KEYS.jsonl \
  --new-report /private/outputs/qwen4b_blind_grade.json
```

Для обучения исходными текстами книга/тест `SOURCE_ONLY` не может доказывать качество трейдера. Независимая экспертная разметка **существует пока только в форме необработанной очереди**; придумывать правильные ответы или засчитывать ответы нейросети за эталон запрещено.

Сравнение запускается только при `source_research_report.json` с `validation_gate.accepted=true`, совпадающих хешах safetensors адаптера и той же локальной HF базы. Если QLoRA не состоялась или адаптер деградировал на текстовой валидации, модель для теста **не принимается**.

**Никакие сделки или публичные публикации оригинальных PDF не выполняются.** Основной проект `19wolfalone92/Williams` (Williams Bot 2.1) не изменяется.
