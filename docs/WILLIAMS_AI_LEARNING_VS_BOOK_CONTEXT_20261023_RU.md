# Williams AI — что именно означает «объяснить AI все четыре книги»

**23 октября 2026.** Реализация: ветка `feature/ai-private-four-books-inference-bridge-20261023`. Код касается **только Williams-AI**, не основного Williams.

## Почему чтение книг ассистентом не означает освоение книг автономной нейросетью

У ChatGPT, индекса SQLite, вычислительных правил Python и отдельной GGUF-модели разные состояния и знания. Даже идеальное обсуждение книги в ChatGPT не записывается автоматически в параметры локальной GGUF на телефоне. Для обучения и самостоятельного принятия решений необходимы **реальные модельные веса**, совместимая исполняющая среда и канал передачи проверенных данных в модель.

Различать:
1. **Исходные правила** — 27 кратких проверенных карточек, *не полная семантическая разметка 642 страниц*. Верно выбранная карточка не доказывает полного понимания рисунков.
2. **RAG-подсказка по первичному тексту** — при одном сценарии читать из личной SQLite только нужные страницы нужного издания; это не меняет веса нейросети, но позволяет отвечать с реальными источниками и объяснениями.
3. **Накопленная учебная память** — последовательный локальный вызов работающей GGUF по страницам, проверка реальных цитат исходного текста и запись **предположительных** выводов в отдельную закрытую SQLite. Это обучение через внешнюю память, **не fine-tuning**.
4. **Дообучение параметров** — отдельный технический процесс, требующий совместимой trainable base модели, размеченных/проверенных данных, оборудования, контрольного набора и конвертации в исполняемый GGUF. Текущий проект **не** обучает GGUF-веса, этого не скрывать.
5. **Визуальное чтение** — текстовая GGUF не видит пиксели книжных схем. Нужен совместимый **vision-GGUF+mmproj**, настоящая оценка на иллюстрациях и эталонных волновых разметках, которых нельзя заменить OCR.

## Что исправлено в этом PR

Раньше в `LocalWilliamsModel.propose_chart_reasoning` попадали только краткие пересказы rule-card реестра и уже рассчитанные OHLC индикаторы. **Реальный первичный текст книги не подавался в историческом многошаговом экзамене**.

Теперь:
- `williams_ai/grounded_inference.py` выбирает 1–3 кратких выдержки **не более 650 символов** из локальной пользовательской базы четырёх книг, проверяет `volumes.sha256` и число страниц по закреплённому оригиналу, **не смешивает издания**;
- `williams_ai/reasoning_trial.py` и `reasoning_batch.py` могут передавать в запущенную локальную GGUF оригинальные выдержки, краткие book-rule карточки и causal H1/H4/D1 исключительно из свечей, известных на момент решения;
- отчёт перечисляет только PDF-страницы, **не выводит авторский текст в GitHub/Actions**;
- `williams_ai/study_cli.py` запускает синхронное **восстанавливаемое самостоятельное чтение всех четырёх книжных индексов** настоящей GGUF, сверяет фактическую принадлежность подтверждающих фрагментов страницам, сохраняет частные черновые уроки. SHA реальных GGUF-весов становится частью ID учебной памяти, чтобы разные модели не выдавали чужое обучение за собственное;
- строгий `algorithm_guard` продолжает не допускать неверные правила, подглядывание в будущее, фальшивые биржевые fills/SL и неподтверждённые «точные» волны. **Никакой реальной торговли и автосделок**.

## Однокомандное локальное изучение (после появления реальных весов)

```bash
python -m williams_ai.study_cli --book-index "/private/Williams_AI_Knowledge_Private.sqlite3" \
  --study-memory "/private/Williams_AI_Study.sqlite3" \
  --local-model "/private/real-chat-model.gguf" \
  --budget-per-book 100 --rounds 6

python -m williams_ai.study_cli --book-index "/private/Williams_AI_Knowledge_Private.sqlite3" \
  --study-memory "/private/Williams_AI_Study.sqlite3" --report
```

Это способ разбирать тексты и накапливать учебные записи. **Сотни просмотренных страниц не равны доказанному пониманию**, и ни один урок не переводится в «книжное правило» без независимого одобрения.

## Закрытый исторический экзамен с настоящим первичным источником

```bash
python -m williams_ai.reasoning_trial --symbol ETHUSDT --bar-index 900 \
  --edition TC2 --local-model "/private/real-chat-model.gguf" \
  --book-index "/private/Williams_AI_Knowledge_Private.sqlite3"

python -m williams_ai.reasoning_batch --local-model "/private/real-chat-model.gguf" \
  --book-index "/private/Williams_AI_Knowledge_Private.sqlite3" \
  --edition ALL --pairs 15 --checkpoints 4
```

Сценарий оценивает модель на **240 ситуациях** (15 пар × четыре исторических времени × четыре издания), фиксирует Unsupported Claims и отсутствие сигналов отдельно. **Он не является готовым испытанием доходности, не обучает веса и не доказывает 100% понимания**. После изучения этих 240 кейсов нужен независимый новый набор для окончательной оценки.

## Что реально блокирует запуск полного цикла прямо сейчас

Не найден доступный конкретный совместимый файл весов автономной локальной GGUF (для картинок — также mmproj), и до настоящего инференса нельзя измерить её понимание или дообучение. Отдельная реализация на Android и приёмка фактического обмена с Demo/Binance не завершены. Нет независимой визуальной разметки большинства рисунков в исходных PDF.

**Проверяемые цели следующей приёмки:** источник страницы указан; модель способна объяснить правило и исключения на неизвестной иллюстрации; решение на закрытых барах не изменяется будущим; последовательность TC2/NTD/Course не смешивается; прогнозы сопоставляются с независимым новым периодом и реальным журналом ордеров; на непроверенных этапах выполнение торговых действий выключено.
