## Отличия второго цикла

- Из-за отсутствия настоящего допуска **V1 используется только как источник продолжения исследования**, не как проверенный торговый champion. Требовать точные `source_commit`, GPU receipt metadata, `candidate_adapter_sha256` и все подтверждения `complete_training/complete_test=true`. Запрещены повтор существующего Kaggle kernel и ошибка подмены parent.
- Base Qwen3-4B revision прежняя (pin), NF4 4-bit double quant, LoRA rank16 alpha32, FP16 GradScaler, DDP 2×T4; 1024 optimizer steps, checkpoint каждые 256, LR снижен до `3e-6`, `source_repetitions=3` для снижения деградации книжных правил; без платных GPU.
- Из TRAIN-only контекста выделены микрозадачи на AC, Alligator и H4/D1, из волн — совместимость, ограничения W4 и подтверждение, из TC2 кампаний — порядок событий и защитные уровни. Все эталоны вычислены CPU из **исходного TRAIN**; отдельные validation/test задачи **не используются** для создания новых уроков.
- Добавлены новые машинно проверенные задачи TC1 risk и NTD AC на train и validation с разными семенами; **32 дополнительных числовых теста** с новым зафиксированным seed остаются только в финальном CPU-аудите. Алгоритм выбора seed может пропускать заранее заданные числовые комбинации, если в них есть дубли вопросов, **не смотря на ответы модели**.
- Старые графики, старый тест 7 ноября и раскрытый числовой тест первого нового цикла — исключительно regression/dev; не являются новым слепым биржевым экзаменом. Рынок и классические волны всё ещё без независимой экспертной аттестации.
- GPU-архив шифруется под неизменный токен получателя (не писать его в логи), открытые GitHub artifacts содержат только ciphertext, замороженный манифест и независимый CPU-аудит.

## Безопасность и допуск

`execution_allowed=false` во всех учебных заданиях, без DEMO/live приказов. Ошибка STOP/oversize/future leakage блокирует продвижение. Критерии прежние: нулевая опасная ошибка, >=80% overall и >=75% по правилам, +5 процентных пунктов относительно baseline там, где применимо, без потери знаний книг. Если CI или GPU-отчёт провалился, результат остаётся в research и никакого Android/бота/главной ветки не затрагивает. Даже успешные учебные результаты не доказывают рыночную доходность.

Контроль остановки: `experiments/deep-corrective-v2-control.json`, `stop=true`. Уникальный Kaggle slug: `williams-ai-deep-corrective-20261110-r2`. Контроллер не запускает GPU при отсутствии родительских весов, переполненной квоте, занятом slug или неверных данных. Публичный git-run свидетельствует только о статусе CI; подлинное обучение удостоверяют лог QLoRA/receipt/CPU audit и SHA нового адаптера.
