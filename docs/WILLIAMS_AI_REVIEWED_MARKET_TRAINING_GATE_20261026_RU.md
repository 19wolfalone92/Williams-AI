# Williams AI — контроль качества реального обучения Qwen + LoRA (26.10.2026)

Статус: **изменён критерий допуска размеченных рыночных примеров к обучению LoRA**, а не веса нейросети. Исходный `19wolfalone92/Williams` не затрагивается.

## Проблема
Раньше набор из 64 «разных» вопросов об одном и том же участке ETH H1 мог удовлетворить проверке количества: фактически это **один рыночный контекст**, а не 64 независимых опыта. Более того, ETHUSDT Spot, ETHUSDT Futures и ETHUSDC считались разными группами при разделении train/test, хотя даты исторических баров и базовый актив пересекаются.

У такой разметки высок риск запоминания отрезка, утечки истории и ложной высокой оценки качества LoRA. Графики всегда неповторимы; учить нужно причинную интерпретацию сигналов **в разных рыночных режимах, на разном масштабе и разных активах**, а не узнавание шаблонов.

## Новый жёсткий допуск для рыночного LoRA/QLoRA
Двумя независимо заявленными проверяющими должны быть одобрены **каждый** конкретный пример, правило и точно запечатанные закрытые свечи. Алгоритм проверки не удостоверяет человеческую квалификацию и не изобретает экспертных меток.

| Выборка | Размеченные примеры (минимум) | Уникальные окна свечей | Базовые активы | Таймфреймы |
|---|---:|---:|---:|---:|
| Train | 24 | 12 | 3 | 3 |
| Validation | 8 | 4 | 2 | 2 |
| Test, не для подбора модели | 8 | 4 | 2 | 2 |

Дополнительно для **каждого** из четырёх изданий (TC1, NTD, TC2, COURSE) — минимум два разных рыночных окна в каждой выборке. Сохраняются прежние правила: неизменная исходная разметка и SHA-256; причинные закрытые свечи без future leakage; исходные книжные страницы; разделение по книжным правилам; эмбарго 24 часа между перекрывающимися историями; ни один test-answer не попадает в fit.

Пересечение теперь проверяется **для базового актива целиком**: ETHUSDT/ETHUSDC/ETHBTC, Spot/Futures не могут занимать перекрывающиеся исторические окна в разных выборках. Это намеренно консервативная защита; она не доказывает одинаковую ликвидность, биржевые издержки или торговую эквивалентность инструментов.

Одинаковый контекст не становится независимым опытом после изменения вопроса, `rule_id` или номера кейса. Аудит показывает количество эффективных окон, активов и ТФ отдельно для train/validation/test.

## Контур обучения — чего ещё требуется
1. **Qwen, понимание первоисточников.** Персональный индекс всех четырёх подлинных книг с цитатами и страницами; самостоятельное чтение по разделам, задачи на новое применение, разбор ошибок. OCR книжных картинок не заменяет их проверку человеком. Сохранённые заметки, поиск страниц и многократная практика — не изменения весов.
2. **LoRA, изменение весов.** Строго лицензированный локальный Hugging Face Qwen, проверенные человеческие обучающие ответы, реальный GPU; обучение только на train, выбор настроек только по validation, независимый test после заморозки модели. Контрольная точка не публикуется как торгово готовая автоматически.
3. **Проверка, действительно ли научился.** Сравнивать исходную Qwen и Qwen+LoRA по новым закрытым графикам **в одно и то же время as-of**: Alligator, AO/AC, пять измерений, WM1/WM2/WM3, вложенные волны D1/H4/H1/M15, «пять пуль», вход/доливки/SL/выход, психологические ограничения. Включать явные случаи «НЕ ВХОДИТЬ», отсутствие фрактального подтверждения, разные тренды/флеты/коррекции, вероятности UP/DOWN/RANGE и проверку их калибровки. Запрещено оценивать ценовую метку будущего, пока её время ещё не наступило.
4. **Отдельная безопасность.** Проспективные paper-кампании с комиссией/проскальзыванием, затем Binance Demo с проверенными защитными ордерами, восстановлением состояния после перезапуска и проверкой Android. Никаких live-ордеров на основании одного учебного отчёта.

## Как проверить приватный JSONL без GPU
```bash
python -m williams_ai.private_lora \
  --reviewed-jsonl /private/reviewed.jsonl \
  --local-hf-model /private/qwen-hf \
  --private-adapter-output /private/new-output \
  --audit-only
```

Поле `market_training_gate.accepted` является **проверкой разнообразия и структуры датасета, не оценкой правильности ответов**. Для источникового текстового исследования по четырём книгам существует отдельный `--source-only-research`: оно не претендует на освоение графиков. Обучение QLoRA на личном CUDA GPU через `python -m williams_ai.qlora_gpu_research` остаётся **ручным и добровольным**, не запускается в GitHub CI, не передаёт в публичный репозиторий приватные книги/картинки/ключи.

### Честная граница этой итерации
Созданы только проверки против повторяющихся графиков и пересекающейся истории. Настоящий GPU fit Qwen, независимые экспертные ответы, калибровка, проверенная доходность, аппаратное исполнение Android и Demo не выполнены. Ни один `PASS` модульного теста не должен называться «обученной моделью» или «100% Биллом Вильямсом».
