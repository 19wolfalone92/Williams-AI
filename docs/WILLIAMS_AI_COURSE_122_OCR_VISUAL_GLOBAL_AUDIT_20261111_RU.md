## 1. Фактическая проверка пользовательских оригиналов

Непосредственно в приватном окружении обработан **оригинальный** PDF Bill Williams — Trading Chaos Course. SHA-256 PDF: `fc57f707378087bfc5146db5e242c51ce8135e0b359f0c607305b364e0decfca` — соответствует `knowledge/SOURCE_RULE_CARDS.json`.

- **122/122** страниц отрендерены как сохраняемые JPEG-сканы, SHA-256 каждого снимка проверен.
- **121/122** страниц получили OCR-текст, **33 862 слова**, **188 189 символов**. PDF-стр. **56** — почти целиком составная волновая схема с номерами/буквами; алгоритм не распознал отдельного надёжного непрерывного текстового блока; сохранена картинка и описательная визуальная ссылка, **никакой текст не выдуман**.
- Повернутые при сканировании PDF-страницы **57, 58, 60, 103** распознаны в правильной ориентации; bbox текста сопоставлены с оригинальной ориентацией страницы.
- **122/122** JPEG связаны с соответствующими OCR-страницами по `pdf_page` и `page_image_sha256`. **68** страниц с диаграммами/таблицами получили описательные ссылки и близкие по тематике OCR-абзацы; **все связи описательные и не подтверждают правильность интерпретации авторского рисунка**.
- Создан **122-страничный поисковый PDF**, текстовый слой есть на 121 странице.
- Выпущены JSONL со словами/абзацами и координатами, `course_visual_links.jsonl`, unverified research cards, персональная SQLite FTS5 и private manifest/QA.
- Сформирован **единый личный SQLite-индекс четырёх книг**, чтобы установка Course не уничтожила прежние TC1/NTD/TC2. Извлечённый текст: **TC1 140/140, NTD 155/156, TC2 224/224, COURSE 121/122 = всего 640/642 страниц**. У NTD одна страница без текстового слоя, у Course — визуальная PDF-стр. 56. Суммарно 1 994 текстовых фрагмента (`excerpts`).
- Приватный архив ~72 MiB сохранён пользователю; сам PDF, изображения, OCR, обучающие карточки и полные книжные цитаты **не коммитились** в публичную ветку.

Модули: `williams_ai/course_visual_private.py`, `williams_ai/grounded_inference.py`, `williams_ai/local_model.py`, `scripts/ai_merge_private_course.py`. ## 4. НОВЫЕ находки повторного аудита и риски, пока неустранимые автоматически

**P0 — неизвестна семантическая точность OCR и рисунков.** Даже уверенность распознавателя выше 90% не гарантирует верность терминов, формул, таблиц, уровней 1–5/A–B–C, стрелок или знаков плюс/минус. Особенно важные PDF-страницы **47–60, 62–72, 78–83, 90, 103, 120–121**. Из 68 описаний нет 68 независимых экспертных рецензий. Страницы со слабым OCR: таблицы/бланки и повёрнутые иллюстрации; следует проверять по изображению.

**P0 — невозможно честно заявить «профессионально изучено всё содержание».** Все 122 страницы технически обработаны, доступны снимки и выровненные текстовые блоки, однако настоящий авторский смысл **каждого** графика/рисунка/математической зависимости не прошёл построчную внешнюю верификацию. Это отдельный слой экспертной разметки, который нельзя синтезировать из ответов модели и объявить доказательством.

**P0 — нет проверенного рынка для QLoRA.** Старый генератор по-прежнему содержит **0 положительных `wave_confirmed` / `squat_verified`** и не является экспертным train gold. Книжный OCR вправе использоваться для private retrieval/research, но **не** как автоматическое эталонное рыночное решение.

**P0 — text-only Qwen3-4B не умеет прочитывать рисунок из пути к JPEG.** Сообщаем модели, что описание рисунка предварительное, а реальные изображения доступны локально для vision-процесса/человека. Нужна отдельная визуальная модель или экспертная работа по графикам и сравнение с первоисточниками.

**P1 — абзацы привязаны к рисункам по странице и лексическим совпадениям, не по доказанному авторскому смыслу.** Возможны несоответствия, особенно на страницах с несколькими схемами. Точный spatial caption-figure detector и ручное исправление для high-priority остаются отдельными задачами.

**P1 — база из 37 коротких рецензированных карточек правил не является исчерпывающим разбором всех 642 страниц.** Новый index расширяет доступность *оригинального содержания*, но не гарантирует знание и правильное практическое применение.

**P1 — учёт прошлых ошибок есть, непрерывного самостоятельного переобучения нет.** Задокументированные/рецензированные ошибки хранятся причинно, и они могут приоритизировать уроки, однако Qwen на новом OCR **не обучалась**, GPU-эксперимент для v2 не запускался. Не менялись рабочие веса.

**P1 — источник лицензированного текста и секретность.** Архив сохранять в закрытой библиотеке, не публиковать через GitHub Actions artifacts/public repo или открытый сервер. Публичная ветка содержит **только код/синтетические тесты/числовые отчёты**.

## 5. Реальный дальнейший контур

1. Установить private ZIP в защищённую директорию вне GitHub, указать путь к `williams_all_four_private.sqlite3` через `--book-index` для локального Python research runner.
2. Через OCR+изображения проверить предметные PDF-страницы, сначала критичные схемы и ошибки чтения; вести `page/image SHA → figure → verified caption → rule → 2 independent reviews`, `UNKNOWN` вместо выдуманной метки.
3. Только затем формировать независимые positive/negative market cases по настоящим закрытым H1/H4/D1, обновлять обучающий корпус и записывать reviewed_error через causal memory.
4. Перед GPU — реальное качество token masks, CUDA gradients, 4-book source preservation, независимые validation gates; train/dev/test embargo.
5. После GPU — отдельный frozen prompts-only process → sealed inference → независимое gold scoring, сравнение parent/candidate, отказ от promotion при регрессии по риску.

**Общий вердикт:** техническая индексация всех 122 страниц завершена, Course доступен для приватного изучения и текстового поиска с явными флажками недостоверности. Полная экспертная визуальная разметка и подтверждённое улучшение Qwen **не выполнены**. Williams Bot и реальная торговля не изменялись.
