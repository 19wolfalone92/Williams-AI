# Williams AI: проверка знаний четырёх книг, графиков и полного цикла — 23.10.2026

## Честный статус

**Нет доказательства, что локальная GGUF-модель знает четыре книги на 100%.** Техническая доступность текста, число успешно обработанных страниц, сохранённые конспекты, тесты Python и экзамен модели — разные метрики. Нельзя подменять одну другой.

В приватном пользовательском индексе по четырём проверенным PDF зафиксировано 640 из 642 страниц с извлечённым текстом: TC1 140/140, NTD 155/156, TC2 224/224, Course 121/122 (OCR). Сканированные рисунки и нюансы OCR требуют визуальной ревизии. В публичный GitHub тексты и личная база не включаются. Курсовые/книжные профили нельзя незаметно смешивать.

PR #3 уже содержит локальные PDF-индекс и контекстный поиск, GGUF-конспекты с происхождением, редактируемую учебную память (без изменения весов GGUF), причинный OHLCV-ридер и исследовательское paper learning. На телефоне модель должна быть отдельно установлена и проверена.

## Конкретное изменение в этом PR

1. Сигнал **TC2 WM3** больше не квалифицируется по Teeth только в момент образования фрактала: цена должна достигнуть уровня после закрытия двух правых баров, и Teeth оценивается в момент наблюдаемого касания. Новые подтверждённые фракталы той же стороны заменяют старые ожидания; двусторонний outside bar помечается неоднозначным. Касание ценой OHLC НЕ означает биржевого исполнения. Проверяем код `williams_ai/chart_reader.py`.
2. Вынесен независимый аудит **торговой кампании**: вход, подтверждение биржевого защитного стопа, интервал без защиты, перенос стопа только в сторону снижения риска, отмена, наблюдение противоположного Мудреца и фактически подтверждённый выход. Тот факт, что появился встречный сигнал, **не доказывает исполнение сделки или оправданность немедленного закрытия**. Это `williams_ai/campaign_audit.py`, режим read-only; прямая сверка с аккаунтом Binance ещё не интегрирована.
3. Заморожены **реальные публичные** H1-свечи Binance Futures для ETHUSDT, SOLUSDT, XRPUSDT: по 240 баров с 12 по 21 октября 2026 UTC включительно. Набор `examples/ai_public_h1_20261022_3pairs.json` содержит только публичные закрытые OHLCV, без ключей и сделок пользователя. В тестах отдельно вычисляются AO, AC; проверяется отсутствие look-ahead, что новые бары не меняют прошлые выводы, и что OHLC-срабатывания не равны fills.
4. Добавлен **экзамен**: десять небольших контрольных вопросов по TC1/NTD/TC2/COURSE, ответы скрыты от модельного контекста, проверка баллов выполняется вне GGUF. Это не слепой и не исчерпывающий тест и НЕ процент освоения книг. Требуется настоящий GGUF для измерения её результатов. В CI тесты используют только имитацию (fake engine).

### Корректные индикаторы в текущем OHLCV-анализаторе

Используется медианная цена `(high + low)/2` и следующие параметры:
- Alligator: **Jaw SMMA(13), сдвиг +8; Teeth SMMA(8), сдвиг +5; Lips SMMA(5), сдвиг +3**; графическое отображение сдвига не подставляет будущие значения;
- AO: **SMA(5, median) − SMA(34, median)**;
- AC: **AO − SMA(5, AO)**;
- NTD Zone: знак изменения AO и AC на последних закрытых барах;
- TC2 WM1 — разворотный бар плюс **пока только численная эвристика ангуляции**; TC2 WM2 — кандидат Super AO, не NTD Saucer; WM3 — минимум две правые закрытые свечи плюс последующий price trigger с фильтром Teeth; волны — альтернативы, а не подтверждённые Elliott-разметки.

Это проверки конкретных формул Python-ридера. Они не гарантируют одинаковую реализацию в Android-коде, корректное визуальное распознавание картинок или прибыльность.
