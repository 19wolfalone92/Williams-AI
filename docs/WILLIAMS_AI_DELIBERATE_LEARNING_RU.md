# Williams AI: перечитать, проверить, запомнить, пересмотреть

Этот цикл использует существующую локальную GGUF-модель и частную библиотеку.
Он обновляет учебную память, не веса Qwen. Ни один самостоятельный вывод
модели не получает статус экспертного ответа, торгового допуска или цитаты.

## Что происходит в разборе

1. AI получает только доступный закрытый срез рынка, правила выбранного
   издания и подходящие прежние заметки именно этой версии модели.
2. Модель может сообщить `learning_need`: ENTRY, MANAGEMENT, EXIT или WAVE.
   Независимый программный критик также может выявить неподтверждённый вывод.
   Корректное NO_SETUP без пробела в правиле завершается ожиданием.
3. Python-путь выбирает конкретные проверенные страницы того же издания
   по теме и ошибке. Отсутствующая диаграмма/неизвлечённый текст остаётся
   пробелом; другой текст не подставляется как доказательство рисунка.
4. Модель читает не более двух исходных фрагментов. Дословное подтверждение
   должно присутствовать в источнике. Сохраняются только непроверенные
   учебные выводы с привязкой к модели, книге и хешу исходного текста.
5. AI один раз пересматривает разбор на **том же** срезе свечей. Источник
   имеет приоритет перед его конспектом. Последний ответ снова проверяет
   независимый программный критик. Повторная ошибка остаётся ошибкой.

Понятное правило при нехватке рыночных фактов не требует угадывания:
нужны новые закрытые данные, а не ещё один проход до желаемого сигнала.
Конкретная степень вложенной волны, биржевой fill и подтверждённый SL
не выводятся из одного перечитывания текста.

## Запуск Python

В `reasoning_trial` при передаче `--book-index` и настоящей локальной модели
цикл включён по умолчанию. Если `--study-memory` не указан, частная память
создаётся рядом с индексом: `Williams_AI_Decision_Study.sqlite3`.

```bash
python -m williams_ai.reasoning_trial --symbol ETHUSDT --bar-index 900 \
  --edition TC2 --local-model /private/qwen.gguf \
  --book-index /private/Williams_AI_private_books.sqlite3
```

`--no-deliberate-study` отключает цикл для сравнения с исходным режимом.
Сравнение на повторно показанном вопросе нельзя называть независимым экзаменом.
Таблица `decision_study_events` хранит диагноз, идентификаторы страниц,
число обработанных фрагментов и хеш среза. Текст книг и ответы модели
в этот журнал диагностики не копируются. Приватные учебные карточки остаются
в отдельной таблице `study_notes` за пределами репозитория.

## Android

Чат использует издание, выбранное в списке книг. Если итоговый ответ
начинается с `[НУЖНА КНИГА: MANAGEMENT]` (также ENTRY/EXIT/WAVE), приложение
перечитывает подходящие страницы **этого** издания, сохраняет одну
подтверждаемую текстом карточку и один раз повторяет разбор с тем же снимком.
`[НУЖНЫ ДАННЫЕ]` и обычное ожидание не запускают чтение до появления сигнала.
Маркер внутри незавершённого/скрытого рассуждения не считается запросом.

Android-поиск остаётся лексическим, а не экспертным пониманием страницы.
Выбор PDF-страницы не доказывает, что извлечён весь рисунок или верно понят
его смысл. Проверка ссылок блокирует распознанные ссылки вида
`[TC2, PDF с. 131]`, если эта страница не подавалась; она не доказывает
истинность всех утверждений и не распознаёт любой возможный формат цитаты.

Исправлена область действия памяти: чужая модель/другое издание не дают
заметок текущему ответу; после изменения исходного OCR старый конспект
не используется. Веса не переписываются, экспертные одобрения не создаются.

## Проверка настоящей Qwen

Отдельный workflow запускает настоящую Qwen3-1.7B-Q4_K_M: первоначальный
ответ на четыре задания по стопам, чтение двух публичных пересказов правил,
проверка цитируемых фрагментов, запись/повторное открытие памяти, ответы
с источником и собственными непроверенными конспектами.

В публичном CI нет оригинальных частных PDF. Такие заметки хранятся в
**другой** таблице `public_rule_study_notes`, их источник явно обозначен
как PUBLIC_REVIEWED_RULE_PARAPHRASE_NOT_ORIGINAL_PDF. Этот опыт не считается
чтением оригиналов, независимым holdout, LoRA или доказательством прибыли.
Неудачный результат модели должен оставаться видимым в отчёте.

Автономные торговые полномочия этот цикл не предоставляет. По-прежнему
нужны независимые размеченные графики, проверка новых рыночных периодов
с издержками, GPU для весового обучения и фактическая биржевая приёмка Demo.
