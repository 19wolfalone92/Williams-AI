# Williams Cognitive Engine 4.0 — план внедрения и критерии слияния
**Дата:** 2026-11-11 · **Источник:** четыре пользовательские оригинальные книги Вильямса · **Режим:** строго исследовательский, без торговых ордеров.

## Цель
Соединить четыре книги, числовую проверку рынка, семантическую/эпизодическую/процедурную память, контргипотезы и обучение на ранее *проверенных* ошибках. Отличать «модель придумала» от «наблюдаемый факт» и «независимо подтверждено». Не выдавать коррекцию памяти за изменение весов Qwen.

### Внешние идеи (не буквальное клонирование)
- TradingAgents: **контргипотезы** с обязательным отдельным критическим проходом; одна Qwen не становится независимым экспертом из-за смены роли.
- FinMem / Letta / Graphiti: **временная и типизированная память** с проверкой источника, а не сырое хранение «всего сказанного».
- FinRobot: вычисления инструментом, объяснения моделью.
- Qlib / RD-Agent: гипотеза → фиксированный эксперимент → отказ/rollback при ухудшении.
- DSPy: улучшение инструкций по ошибкам, но **только на train/dev**, без подглядывания в test.

## Критическая архитектурная совместимость с текущими ветками
- `main` и `research/fifty-serial-mini-cycles-20261110` **разошлись**: у research 112 новых коммитов, у main 5 собственных. Большое прямое слияние в main без интеграционных тестов может перезаписать обновлённые `book_index.py`, `knowledge.py`, `SOURCE_RULE_CARDS.json` и рабочие учебные скрипты. Запрещено автоматически перезаписывать эти изменения.
- PR #75 изначально направлен **НЕ в main**, а в `research/fifty-serial-mini-cycles-20261110`. Merge PR #75 сначала объединяет только исследовательские ветки.
- Нельзя переносить сами PDF, OCR, страницы или секреты в публичный Git/CI.
- Нельзя считать пройденный CPU suite доказательством GPU-качества, прибыльности либо готовности к торговле.

## Реестр рисков и критерии приёмки
1. **P0: временная утечка из долгой памяти:** видимость начинается не раньше _фактического recorded_at_, даже если `available_at` был задним числом.
2. **P0: самоподтверждение знаний:** `source/vision/silver` остаются непроверенными до независимой подлинной рецензии, никакой «confirmed» метки из результата LLM.
3. **P0: источник ≠ торговое решение:** книга указывает применимое правило, система не выдаёт ордер, stop/size и риск считаются отдельно.
4. **P0: несовместимость веток и SQLite:** новые таблицы versioned, старые сохранены; `main` имеет собственные коммиты.
5. **P1: синонимы и язык:** BM25 + pluggable local embeddings, сопоставление paraphrases как отдельный тест.
6. **P1: режимы рынка и волновые ошибки:** вердикт всегда может быть WAIT/UNKNOWN; отбор сложных уроков только после разметки.
7. **P1: эффект памяти и критика:** требовать A/B/C на одном blind exam и нерегрессии risk, не рекламировать увеличение IQ до измерений.

## Стратегия слияния
Сначала слияние **в указанную исследовательскую базу PR #75** при зелёной CI и отсутствии регрессий. Затем отдельное интеграционное PR к `main`, без автоматического продвижения новой QLoRA и без прав на сделки. Если данные, безопасность или совместимость `main` непроверены — main остаётся неизменным.
