# Williams AI: интернет-исследования и DEMO-торговля

## 1. Когда AI не знает ответа — поиск

Android-приложение использует локальную GGUF-модель, без облачного AI API.
По умолчанию **интернет-поиск выключен**. Пользователь отдельно отмечает
«🌐 Искать в интернете…». После этого при явной просьбе что-то найти,
проверить, узнать новости или при сообщении модели о недостатке знаний
приложение обращается к **ограниченному списку публичных HTTPS-источников**:

- Русская Википедия: API поиска, без ключа.
- Google News: RSS, без ключа.

Модель получает только найденные заголовки, короткие фрагменты и ссылки,
а не произвольные команды из сайтов. В ответе добавляются URL источников.
Недоступные сайты и отсутствие результатов обозначаются явно. Никаких
API-ключей OpenAI, облачных моделей или внешнего облачного «мозга» нет.

**Ограничения:** это начальный веб-поиск, не полный браузер. Wikipedia и
новостной RSS не покрывают торговую документацию и научные статьи полностью.
LLM может неправильно интерпретировать контент — сверять первоисточники.
Интернет расходует трафик; поисковый вопрос передаётся внешнему провайдеру.
Не помещайте секреты/API-ключи в поисковый вопрос. Поисковые результаты НЕ
являются торговыми сигналами и никогда не вызывают торговые функции.

## 2. DEMO Futures: разрешён отдельный защищённый исполнительный модуль

В Python реализован **демо-only исполнитель**, который физически допускает
только хост https://demo-fapi.binance.com и ограниченные Binance Futures
USDT-M endpoints. Это не production-биржа и не финансовая рекомендация.

- По умолчанию OFF, даже при наличии демо ключей.
- Поддерживаются BTCUSDT, ETHUSDT, SOLUSDT, XRPUSDT.
- За один экземпляр максимум две попытки; отдельная заявка истекает через
  45 секунд. Лимиты: номинал до 150 DEMO USDT, структурный риск до 3 DEMO USDT.
- Требуется явно подтвердить DEMO_ACCOUNT_ONLY и PLACE_DEMO_ORDER.
- Проверяется режим One-way (BOTH), отсутствие позиции на паре и фильтры
  MARKET_LOT_SIZE / PRICE_FILTER.
- STOP_MARKET closePosition=true размещается и проверяется на бирже **до**
  входа. Если не принят биржей, вход не производится.
- После входа SL перепроверяется. Если подтверждение пропало, попытка
  закрытия reduceOnly с блокировкой повторных входов.
- При сетевой неопределённости повторный MARKET не делается и SL НЕ
  отменяется. Необходимо ручное восстановление по биржевому состоянию.
- **Нельзя передавать произвольный текст нейросети прямо исполнителю.**
  Модель не имеет полномочий вызывать этот модуль.

### Пробный расчёт без ключей

Из корня репозитория:

    python -m williams_ai.demo_cli \
      --symbol ETHUSDT --side BUY --quantity 0.2 --stop 95

Уровень stop 95 указан только для примера; программа откажет, если он
нелогичен при текущей демо-цене. Установите реальный структурный стоп
по результатам анализа, а не из примера.

### Попытка реального (симулированного деньгами) DEMO ордера

Создайте **отдельные ключи Binance Futures Demo Trading** в демо-аккаунте,
никогда не применяйте ключи основного Williams Bot.

    python -m williams_ai.demo_cli \
      --symbol ETHUSDT --side BUY --quantity 0.2 \
      --stop <ваш_защитный_уровень> --send

Введите демо API key/secret в скрытом вводе терминала и две фразы
подтверждения. Никаких ключей в git, параметры командной строки и файлы.

**Фактическое DEMO-исполнение не проверено:** CI использует мок-биржу.
На реальном DEMO потребуется проверить, поддерживает ли текущая биржа
предварительное размещение закрывающего STOP_MARKET без позиции.
Если не поддерживает — приложение правильно откажется входить.

## 3. Что остаётся

- Android-чату ещё не подключён исполнитель Python: на телефоне доступен
  web-assisted анализ, а DEMO операции доступны из отдельного Python CLI.
- Нужны устойчивые расчёты по закрытым свечам, стратегия кампаний, история,
  восстановление после перезапуска, долговременное подтверждение SL,
  журнал сигналов, DRY_RUN и fault-injection на реальном Binance DEMO.
- Режим **автоматической** торговли нейросетью НЕ включён. Это отдельный
  этап после проверки правил Вильямса и инфраструктуры защиты.
- Основной репозиторий Williams и реальный торговый счёт не затронуты.
