GitHub Actions может удалять старые артефакты по сроку хранения; архивные копии не должны публиковаться в публичном репозитории. Не коммитить LoRA веса, первоисточники, ключи или закрытые результаты.

## Fail-closed критерии дальнейшего допуска

1. Независимо восстановить веса кандидата по контрольной сумме и выполнить полный зафиксированный экзамен на одинаковых исходных вопросах.
2. Для критических заданий требовать **нулевые пропуски STOP** и **нулевые превышения риска**, плюс прохождение precommitted AC/NTD/TC2 и книжных регрессионных порогов.
3. Запретить future leakage, непроверенные метки волн, самовольное ослабление risk rules, исполнение по неполным JSON и подмену эталона.
4. До отдельной явной команды после всех проверок — **никакой активации торговых решений AI, DEMO/live ордеров или установки обученного адаптера в Android**.

Этот документ фиксирует границы интеграции, а не подтверждает достижения торговой квалификации.
