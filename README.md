# Williams AI

Независимый исследовательский проект на основе копии Williams Bot.

**Основной торговый бот:** https://github.com/19wolfalone92/Williams — не изменяется в рамках Williams AI.

Williams AI предназначен для анализа рыночных данных, объяснения торговых решений и воспроизведения сценариев без исполнения реальных сделок. Импорт исходного кода будет закреплён за конкретным коммитом основного проекта. Торговые ключи и секреты не копируются.

> Статус: инициализация. Нет разрешения на реальные операции с биржей.
