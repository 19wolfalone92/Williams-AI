# Williams AI 🧠

Независимый проект анализа рынков и объяснения сигналов, основанный на
**снимке исходного кода** [Williams Bot](https://github.com/19wolfalone92/Williams).

**Здесь нет разрешения на реальную торговлю.**
Исходный бот не изменяется. API-ключи, подписывающие ключи и
CI/workflows оригинального репозитория намеренно не копируются.

Этот репозиторий содержит копию исходного кода для экспериментов,
а не обновление установленного торгового APK.
Сведения о происхождении копии: [SOURCE_SNAPSHOT.md](SOURCE_SNAPSHOT.md).

Начальный этап: отдельный аналитический контур с объяснимыми
решениями и проверками на исторических данных.
