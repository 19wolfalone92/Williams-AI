**15 ноября 2026**, исследовательская ветка; первоисточники пользователя, PDF-страницы считаются с единицы. Это документально проверенная **выборка ключевых страниц**, НЕ прочтение всех 642 страниц и НЕ независимая разметка 100 графиков.

## 1. TC1 — Trading Chaos, PDF 72–74, 89–93

На PDF 72 описана потеря действия фрактального сигнала при возврате к исходному уровню с учётом тика. PDF 73 рассматривает стартовый фрактал/сигнал, возможный стоп либо стоп-и-разворот при противоположных фракталах, а в развивающемся тренде — перенос стопа по противоположным фракталам. PDF 89–93 показывают кампании с многоуровневыми волнами, фракталом и Squat, где волновые цели носят условный характер. **Гипотеза, целевой уровень, существующая заявка и подтверждённое исполнение — разные события.** Нельзя приписывать TC1 одно правило выхода, автоматически выведенное из TC2.

## 2. NTD — New Trading Dimensions, PDF 99, 103–104

Для Линии Баланса сначала определяют базовый бар; сравнение ведётся по максимумам для покупки и минимумам для продажи. PDF 103: при движении **от** Балансовой линии нужен один новый более высокий максимум (или низкий минимум в продаже), при движении **к** ней — два. PDF 104: действующий стоп-сигнал не надо двигать на каждом последующем баре; требуется менять его только по условию формирования новой базы. **Линия Баланса — отдельное пятое измерение**, а не синоним Третьего Мудреца TC2. Для NTD с модельными ответами ABSTAIN 25/25 и 22/25 технически неуспешных ответов GPU LoRA нельзя считать книгу освоенной.

## 3. TC2 — Trading Chaos 2, PDF 121–124, 135–139, 147–149

PDF 122: действительный разворотный бар требует соответствующей формации и расходящейся ангуляции по траекториям цены и Аллигатора; **просто большое расстояние до Jaw не доказывает ангуляцию**. PDF 124: без явного расхождения двух направлений разворотный сигнал считается недействительным.
PDF 137–139: WM2 строится по трём последовательным изменениям окраски AO в сторону нового движения, после третьего бара выставляется стоп-заявка за его ценовым экстремумом; **AO-сигнал не равен подтверждённому исполнению ордера**.
PDF 147–149: WM3 фрактал для LONG должен сработать **выше** красной линии Teeth; для SHORT **ниже**. Критично положение Teeth именно **в момент срабатывания**, а не только формирования. Новый фрактал способен заменить ещё не сработавший сигнал. Это отдельные состояния: formation → pending trigger → actual price crossing → Teeth filter → exchange fill.
**100 исторических H1-кейсов TC2 не содержат подтверждённого состояния реальной позиции**, поэтому нельзя считать ответ HOLD или EXIT_LONG реальным сопровождением кампании.

## 4. Profitunity Course — оригинальные скан-изображения PDF 43–45

PDF 43–44 (Level II): порядка **100–140 баров** нужно рассматривать для контекста степени волны, а 5/34/5 Oscillator, проходящий через нулевую линию, даёт **минимальную индикацию W4**, НЕ доказанное окончание W4. Простое касание AO=0 **не есть** переход с одной стороны нуля на другую. Проверки a–b–c/треугольника, меньших волн и целевой зоны W5 остаются. На PDF 45 отдельно рассматриваются признаки вершины W5 и расхождения. Подмена диаграммы OCR-словами недопустима: нужны визуально проверенные аннотации.

## Выявленные причины пробелов Williams AI

- По каждому из четырёх разделов исторический набор содержал **один фиксированный тип вопроса на книгу** ×25 символов, а не полную проверку вариантов WM1/2/3, книг, волн и сопровождения.
- Инференция RAG отдаёт максимум **3 краткие карточки** на запрос. Даже 100 разных графиков не гарантируют охват всех правил.
- Не задана реальная позиция, цена срабатывания стоп-заявок и статус биржи для TC2; модель не должна выдумывать эти состояния.
- Нет экспертного gold, нет проверенного по первичным источникам волнового счёта, нет независимого стороннего согласования. Технические ABSTAIN нельзя оценивать как правильное торговое бездействие.
- Параметры обучения/Qwen и декодер допускают короткие причины без проверяемого evidence-chain и слишком много ошибок JSON. Для следующей версии требуется структурный отчёт «правило → свечи → условия/противопоказания → альтернативы → решение/воздержание».

Кандидатные типы учебных случаев: TC1 отмена фрактального сигнала; NTD новая база и 1-versus-2 бара; TC2 MW1 ангуляция, MW2 AO третьего бара, MW3 Teeth at trigger, штатный / противоположный выход с открытой позицией; COURSE W4 «касание vs пересечение нуля», степень волны, W5 divergence.
