# Williams AI v6 — доказанный промежуточный итог исторического экзамена 100 H1

**Дата:** 2026-11-15. **Статус: НЕ завершено**. Это исследовательские предсказания, не сертификат торговых сигналов.

## Исходный рынок
Зафиксирован список 25 фьючерсных инструментов Binance USD-M × 4 исторических среза = **100** графиков по **1024 закрытых H1** каждый (102400 баров). Источники проверены по официальным ZIP + .CHECKSUM SHA256 (200 архивов). Будущие бары отдельно сохранены и не передавались моделям. У 100 графиков **нет независимых экспертных gold-меток** по TC1/NTD/TC2/Course; нельзя вычислить процент правильных торговых решений, тем более заявить 95–99%.

## GPU T4: 98 из 100 настоящих сравнений восстановлены

Выполнена реальная инференция Qwen3-4B Base и подлинной v5 LoRA (обучение 80 шагов) на Kaggle NVIDIA Tesla T4, HuggingFace/NF4 backend. GitHub [read-only salvage SUCCESS 43658053110](https://github.com/19wolfalone92/Williams-AI/actions/runs/43658053110), [artifact 14138509043](https://github.com/19wolfalone92/Williams-AI/actions/runs/43658053110/artifacts/14138509043): **98 пар / 196 ответов**, `complete=false`. Финальная ошибка 99-го графика: `GPU_PROMPT_TOO_LARGE_WITH_20_CLOSED_BARS`.

| Показатель на 98 GPU-графиках | Base | Обученная LoRA |
|---|---:|---:|
| Всего реальных ответов | 98 | 98 |
| Корректное завершение JSON, finish=`stop` | 42 | 64 |
| Ошибка декодера, finish=`error` | 56 | 24 |
| Ограничение длины, finish=`length` | 0 | 10 |
| Ответ `ABSTAIN` (включая технические отказы!) | 86 | 62 |

| `WAVE_HYPOTHESIS` | 0 | 12 |

Различаются **46 из 98** выбранных категорий = **46.9%**, это НЕ метрика точности и НЕ доказательство того, что LoRA поняла Вильямса. На TC1 обе модели выдали 25 `ABSTAIN` из 25; на TC2 LoRA выдала 24 `INSUFFICIENT_DATA` из 24, Base имела 23 технических ошибки; на COURSE у LoRA 12 гипотез волн, Base имела 24 ошибки. В GPU-результатах много технических ABSTAIN: **56 из 86 Base** и **34 из 62 LoRA** возникли при error/length, а не в результате осмысленного решения воздержаться.

**Важный нюанс:** GPU использовал максимум 3200 prompt-токенов и 20–48 последних H1 свечей плюс детерминированные каузальные H1/H4/D1 признаки. Это не тождественно GGUF/CPU более длинному контексту, поэтому результаты двух backend нельзя складывать в одну «точность».

## CPU GGUF: 30 из 100 независимых пар завершены (на момент отчёта)

Из 10 CPU-шардов успешно завершены 0,1,2: **30 пар / 60 реальных ответов**; [GitHub Actions 43639364206](https://github.com/19wolfalone92/Williams-AI/actions/runs/43639364206) и три проверяемых artifact. В этих 30 случаях Base vs v5 LoRA решения различаются **в 7 случаях**. Base: `ABSTAIN 16, HOLD 6, WAVE_HYPOTHESIS 7, NO_SETUP 1`. LoRA: `ABSTAIN 17, INSUFFICIENT_DATA 6, WAVE_HYPOTHESIS 7`. В Base имеются противоречия между текстом `INSUFFICIENT_DATA` и выбранным классом, что требует отдельной диагностики, но не является экспертным золотым ответом.

## Что сделано для доведения до 100+100

Оригинальный монолитный CPU run 43588651963 был корректно обозначен как cancelled (лимит 355 минут, 40 Base/0 LoRA). Для CPU запущена 10-шардовая проверка, каждый шард отдельно проходит реальный Base и v5 и даёт отчёт 10+10.

GPU повреждён не в весах и не из-за закрытых баров: сначала путь приватной LoRA, затем CUDA attention OOM (6.96 GiB попытка при 3.64 GiB свободно), затем 99-й длинный prompt. Сохранены 98 SHA-сопоставимых пар. После прямого разрешения пользователя на завершение запущен **один отдельный GPU job только для двух оставшихся случаев `HIST100-25-3`, `HIST100-25-4`** с явно документированным fallback до 4096 input-токенов и минимум 16 H1; первые 98 не пересчитываются. Контроль и строгая сборка [Actions 43658377350](https://github.com/19wolfalone92/Williams-AI/actions/runs/43658377350) должны вернуть 100 Base + 100 v5 только при реальном успехе двух GPU ответов и проверке одинакового prompt/chart SHA в каждой паре. Последние 2 case имеют отдельную политику длины prompt; эти 100 GPU-кейсов **не абсолютно однородны по контекстной политике**.

## Критерий успеха и ограничения

- `complete=true`, 100 уникальных case ID, 100 реальных Base и 100 подлинных обученных LoRA, проверенные SHA источников/весов/попарного model input — только это является завершением **инференции**, но не экзаменом правильности решений.
- Должны быть указаны все `finish_reason=error/length`. Воздержания по ошибке декодера не считать правильными решениями.
- Для реального book accuracy необходима независимая экспертная разметка TC1/NTD/TC2/Course, prospective H1 holdout и проверка no-lookahead; ни одна из этих процедур не доказана одним 100-case прогоном.
- Ветка research, **main не менялся**, реальных торговых ордеров нет.

**Итог:** модель действительно дообучена и применена к проверенным реальным историческим свечам; строгий процент знаний Билла Вильямса пока **НЕ ОПРЕДЕЛЁН**. Дальнейшая техническая часть — успешное получение последних двух GPU-ответов и завершение оставшихся CPU-шардов.
