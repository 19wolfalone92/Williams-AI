# RULE_CHECK_016 — NTD: иерархия четырёх решений выхода, противоположный сигнал не реверс автоматически

**Источник:** NTD, PDF SHA-256 `855eb052353c852f208436952b12e46d9a18badf7c1dac7ade7580d57b9f4bb4`, pages 115–120, Figures 9-1…9-9. Прочитан текст pp 115–120 и визуально просмотрены exit diagrams.

## Четыре описанных рыночных выхода (p 115)
1. **Red Teeth line** (Alligator Teeth): основной stop-only-on-close / market-on-close критерий в продолжающемся тренде. Intraday вариант контролирует закрытие каждого используемого таймфрейма и закрывает после close за линией.
2. **Five consecutive same-colour bars:** после пяти зелёных bars в long — stop один tick ниже low пятого bar; после пяти красных в short — stop один tick выше high пятого bar. После старта trailing stop переносится за последующие полностью закрытые bars; его сохраняют до фактического выхода, даже если поздние бары меняют цвет.
3. **Green Lips line for fast/running market:** использовать для стремительного рынка, когда наклон цены круче наклона Green line; stop-on-close определяется по Lips для следующего временного периода. Это не универсальная замена Teeth в обычном тренде: на обычном тренде этот стоп может вывести слишком рано.
4. **Opposite-direction signal:** это скорее тревожный/исполнительный сигнал выхода и наименее предпочтительное решение. Книга говорит, что обычно нужно выйти, а не автоматически делать stop-and-reverse: длинную позицию закрывают по qualifying sell signal, который сам расположен выше пасти; при short зеркально — buy signal ниже пасти. Постоянное использование слишком рано закрывает прибыльные кампании.

## Приоритет и состояние
- Если несколько stop placements доступны, книга обычно предпочитает five consecutive same-colour bars; противоположный сигнал — последняя по предпочтительности остановка.
- NTD различает выработку сигнала и exit decision; реальное закрытие позиции должно иметь отдельное подтверждение биржевого fill.
- Последовательность: position verified → exit criterion observed on closed bar → stop/close decision armed → exchange order/market action → confirmed fill. «Opposite setup» без закрытия/триггера не меняет реальное состояние позиции.
- Этот материал NTD нельзя автоматически переносить на отдельные правила реверса TC2 или TC1.
